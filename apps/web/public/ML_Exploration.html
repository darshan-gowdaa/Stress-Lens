4. Semantic Search Mechanism (Vector Cosine Similarity)¶

Discover thematic clusters across student check-ins using unit-normalized cosine similarity.

In [24]:
def semantic_search(query_vec, doc_vecs, top_k=3):
    scores = dot(doc_vecs, query_vec) / (norm(doc_vecs, axis=1) * norm(query_vec) + 1e-9)
    top_indices = np.argsort(scores)[::-1][:top_k]
    return [(int(idx), float(scores[idx])) for idx in top_indices]

# Pad tfidf query with zeros for sleep_hours and valence dimensions
query_tfidf = tfidf.transform(["exam anxiety sleep deprivation"]).toarray()[0]
query = np.concatenate([query_tfidf, [0.0, 0.0]])  # match X_test 502 dims
results_search = semantic_search(query, X_test, top_k=3)
print("Top semantic matches (index, similarity score):")
for idx, score in results_search:
    text = X_test_raw.iloc[idx]
    snippet = text[:80] + '...' if len(text) > 80 else text
    print(f"  [{idx}] score={score:.3f}  '{snippet}'")

6. Differential Privacy & k-Anonymity Stress Analytics¶

Department-level aggregations filtered to groups where k >= 5. Laplace noise applied with epsilon=0.5.

In [26]:
k_min = 5
eps   = 0.5
sensitivity = 1.0  # query sensitivity for mean stress

aggs = df.groupby("dept_hash")["stress_level"].agg(["mean", "count"]).reset_index()
aggs.columns = ["dept_hash", "mean_stress", "count"]

# k-anonymity filter
valid = aggs[aggs["count"] >= k_min].copy()

# Laplace mechanism noise
np.random.seed(42)
valid["noisy_mean"] = valid["mean_stress"] + np.random.laplace(0, sensitivity / eps, len(valid))
valid["noisy_mean"] = valid["noisy_mean"].clip(1, 10)
print(f"Departments satisfying k>={k_min}: {len(valid)} / {len(aggs)}")

fig, axes = plt.subplots(1, 2, figsize=(14, 4.5))
axes[0].bar(range(len(valid)), valid["mean_stress"], color="#6366f1", label="True Mean")
axes[0].bar(range(len(valid)), valid["noisy_mean"], color="#f43f5e", alpha=0.6, label="Noisy Mean")
axes[0].set_title("Laplace-Noised Stress Means by Dept (epsilon=0.5)")
